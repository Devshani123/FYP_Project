# Smart Traffic Routing Assistant

Final Year Project — BSc (Hons) Computer Science, Staffordshire University UK

## Overview
An uncertainty-aware deep learning framework for urban traffic forecasting and adaptive route re-planning, using fused Madrid traffic and weather data.

## Tech Stack
- Python
- LSTM & GRU with Monte Carlo Dropout
- OSMnx & NetworkX
- Streamlit
- Folium

## Features
- Traffic intensity prediction using LSTM model (R² = 0.862)
- Uncertainty estimation using GRU + Monte Carlo Dropout
- Adaptive route re-planning triggered by congestion confidence levels
- Interactive Streamlit web application
- Real Madrid road network using OSMnx

## Dataset
MLDAS Madrid dataset — fused traffic and weather data
